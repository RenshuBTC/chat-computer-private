Chat Computer's own system

Chat Computer Setup has started.

  1. Windows asks whether Chat Computer Setup may make changes: choose Yes.
  2. Press Enter to put Chat Computer next to Windows.
  3. Restart the PC: Chat Computer starts. To go back to Windows, ask Chat Computer to restart.
  1. Terminal opens with Chat Computer Setup: type y when it asks to go ahead.
