Chat Computer Setup for Mac

Open Terminal (in Applications, then Utilities), paste this line and press Return:

curl -fsSL https://chatcomputer.ai/get/mac.sh | bash

It puts the Chat Computer app in Applications, with no password, checks it's the one published here, and opens it.

Its next version asks how you want Chat Computer, as the Windows Setup does: as an app, or as its own system next to macOS (on a Mac with M1, M2 or M3). Until it's here, this line installs the app.

Or download the disk image and drag Chat Computer to Applications: the first time, macOS says it can't check the app; open System Settings, Privacy & Security, and choose Open Anyway. (From Terminal, macOS doesn't ask.)

Talk, type or touch. Chat Computer does the rest.

On Windows, one Setup: Chat Computer as an app, or as its own system. On a Mac, with the Mac app's next version.
