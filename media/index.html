Chat Computer

A computer you talk to: an operating system written from scratch in Rust, with Meta's Muse Spark as its brain. Our entry to the Meta Global AI Developer Hackathon.

Recorded in a virtual PC (QEMU): the system's own kernel sends the conversation and its tools to Meta's Model API over its own network stack and TLS 1.3, and Muse Spark runs the computer through tool calls.
